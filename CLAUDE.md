# Тестовое задание в Альфа-Банк — «Дизайн-процесс в Альфа-Бизнес»

Отдельная страница, к сайту kupdasha.ru не относится. Адрес — https://kup-version.kupdaria26.workers.dev/alfa/ (как у «Армии спорта»).
Код и картинки лежат на GitHub kupdasha/alfa (публичный). Воркер kup-version берет index.html с GitHub по последнему коммиту main и ставит `<base href>` на jsDelivr по номеру того же коммита — файлы (al.js, al.css, fonts, img) не идут через workers.dev, который в России часто не открывается без VPN (схема как у «Армии спорта»). Схема один в один как у «Армии спорта»: стили и код только с jsDelivr. Гонку источников и сервис-воркер пробовали 02.11 и убрали: через workers.dev файлы идут плохо, страница стала хуже (sw.js оставлен как самоудаляющийся). `/alfa/check` — диагностика каналов. Не публиковать без нужды: новая версия на jsDelivr первый раз собирается медленно. Адрес `kup-version.kupdaria26.workers.dev/alfa/` менять нельзя: он уже у работодателя.
Выкладка — `./publish.sh "что изменилось"`: проверка кода, push на GitHub, прогрев jsDelivr; воркер новую версию видит сразу. Поисковики не индексируют (noindex).
Из-за `<base>` все ссылки по странице (#v1, #faq) прокручиваются кодом, а не переходом по якорю.

## Файлы
- `index.html` — каркас со скелетом загрузки; `al.js` — вся страница: тексты (из макета «альфа.fig», не править — только типографика, типограф ty() как на kupdasha.ru), картинки, живые блоки; `al.css` — оформление.
- Живое: задание и анализ свернуты в одну строку; переключатель «рус / eng» у обложек (английская версия грузится по нажатию); пайплайн Claude → Blender → Higgsfield → Figma; ролик из Blender (img/scene.mp4, на телефоне scene-s.mp4); HUD kit — 40 векторов из макета лентой по кругу (img/hud.json грузится, когда лента близко); «логотип ⇄ схема» — геометрия из макета, сменяется сама; вопросы раскрываются; в конце маскот едет на такси вправо.
- `img/` — webp (-s — 900 px для телефона). Кадры обложек и ресайзов отрендерены из .fig своим скриптом (векторы и текст — из макета), схема первого варианта — из присланного PDF schema-v7-source.

## Правила
Как у кейсов сайта: без оранжевого, без «·», без нумерации «01/02», без капса (кроме самих макетов), текст не мельче 16 px, кнопки с заливкой и строчные.
